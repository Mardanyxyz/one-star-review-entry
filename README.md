A deadpan one-star review of sleep — the everyday essential nobody can opt out of — for make.fun's "One-Star Review of Something Essential" bounty. Eight hours every single night, and the reviewer still wakes up tired; no refund, no complaint form, no manager, and somehow they keep rebooking. The program validates the review (one line, at most 160 characters) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
